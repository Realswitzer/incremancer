## Used upgrade ranges

When adding a new construction or upgrade, the following are already used:

| Ranges                    | Description                                                                                                                     |
| ------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| 1-17, 19-30, 40-48, 60-61 | Note: 18 is a removed upgrade present in very early version of the game                                                         |
| 62-74 (DM)                | Danemancer upgrades                                                                                                             |
| 101-105, 108-115          | 106-107 are also removed upgrades from a very early version. 115 is the talent point which is excluded from main upgrade menus. |
| 201-222                   | Base game constructions                                                                                                         |
| 301-304 (DM)              | Danemancer constructions                                                                                                        |
