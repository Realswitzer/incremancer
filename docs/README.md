# incremancer/docs

Intended on being a budget wiki with guides on adding new content (items, spells, etc) with pointers on what to change.

Modding guides will expect _mild_ JS knowledge, especially enough to compile and test changes.

Folders:

- `/docs/build` - Builds, deployments, non-game content
- `/docs/modding` - Guides for adding new items, content, etc.
